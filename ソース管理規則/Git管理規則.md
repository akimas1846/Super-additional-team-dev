# Git管理規則

## 開発する前に
開発をする前にフェッチしdevelop,origin/developの状態を同期させておく 
```
git fetch
git pull
```

## 新しく開発をするとき
ブランチ管理規則に則ったうえでブランチを作成し、命名規則を守った開発を行う \
消えても問題ないよう、適宜コミット、プッシュを行う事


## 開発を終えるとき
開発を終えるときは、現在のローカルブランチにコミットをし、リモートブランチにプッシュをする \
プッシュ先はdevelopではなく、自身の作業ブランチの親ブランチに行う 

```
git switch {作業ブランチ}
git commit {commit message}
git push 
```
コンフリクト発生時は親ブランチの共同開発車と話しをし、どれを取り入れるかの選択を行う
```
git switch {コンフリクトを起こしたブランチ}
git status 
```
