# 命名規則

## Java

### オブジェクト宣言名

Upper Camel caseを利用すること

| 種別       | Mapper                                      | 例                                                           | 
| :--------: | :-----------------------------------------: | :----------------------------------------------------------: | 
| Class      | クラス名                                    | public class Booking{ ~                                      | 
| Interface  | 継承先のクラス名 + 任意の変数名 + Interface | public interface ArtInfomationInterface extends Art ~        | 
| Repository | Repositoryで扱うクラス名 + Repository       | public interface CategoryRepository extends JpaRepository( ~ | 
| Mapper     | Mapperで扱うクラス名 + Mapper               | public CategoryMapper ~                                      | 
| Entity     | 変数名 + Entity                             | public class UserEntity ~                                    | 
| Service    | 変数名 + Service                            | public UserDataService ~                                     | 
| Model      | 変数名 + Model                              | public AccountModel ~                                        | 

### メソッド名

Lower Camel caseを利用すること \
例: void selectBook(){

### 変数名

Lower Camel caseを利用すること \
例: int bookId = 1;

#### コンストラクタ生成時の変数名

(任意の変数名) + クラス名 + 対応するオブジェクト とすること \
例: Booking BookingClass = ...
